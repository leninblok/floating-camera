# Floating Camera (Electron)

Плавающее круглое окно с видео с фронтальной камеры, всегда поверх окон.

## Возможности
- **Круглое окно** по умолчанию 250×250, прозрачный фон вокруг.
- **Всегда поверх**: frameless, на macOS используется уровень `screen-saver` и показ на всех рабочих столах/фуллскринах.
- **Видео** через `getUserMedia` (фронтальная камера), перетаскивание мышью.
- **Горячие клавиши**:
  - `S` — смена размера по пресетам: 150 → 250 → 350 → 450 → 550 (по кругу). Работает только в свободном режиме.
  - Двойной клик по кругу — фокусный режим: центрируется и увеличивается (750×750), перетаскивание и изменение размера отключены; повторный двойной клик возвращает назад.
  - `B` — вкл/выкл рамку (сохраняется между запусками).
  - `H` — вкл/выкл зеркалирование видео (сохраняется между запусками).
- **Рамка**: реальная `border` с динамической толщиной
  - 150 → 0.5px, 250/350 → 1px, 450/550 (и более) → 2px.
- **Сохранение состояния**: позиция/размер, флаг рамки и зеркалирование сохраняются между запусками.
- **Плавные переходы**: смена пресетов размеров по `S` и вход/выход в фокусный режим выполняются с анимацией.

## Запуск
1. Установить зависимости
   ```bash
   npm ci
   ```
2. Запустить в dev
   ```bash
   npm start
   ```

macOS может запросить разрешение на камеру. Если не появилось:
- System Settings → Privacy & Security → Camera → разрешить Electron/IDE/Terminal.

## Сборка (macOS)
- Подготовлен скрипт сборки через `electron-builder`:
  ```bash
  npm run dist
  ```
- В `package.json` добавлен ключ `build.mac.extendInfo.NSCameraUseContinuityCameraDeviceType: true` для подавления предупреждения AVFoundation о Continuity Camera в собранном `.app`.

## Структура проекта
- `package.json` — скрипты, зависимости, конфиг сборки.
- `main.js` — главный процесс: создание окна, всегда‑поверх, IPC для получения/установки рамок окна и настроек.
- `preload.js` — безопасный мост IPC (`electronAPI`).
- `index.html` — минимальный UI: `div.circle` с `video`, ошибка.
- `renderer.js` — запуск камеры, перетаскивание, пресеты размеров (`S`), фокусный режим (dblclick), переключение рамки (`B`) и её динамическая толщина.
  Также содержит переключатель зеркалирования (`H`) и сохранение его состояния.

## Примечания
- Ручное изменение размера отключено (окно фиксированно, меняется только логикой приложения).
- На macOS окно поднимается уровнем `screen-saver` и показывается на всех рабочих столах.
- Для продакшн‑сборок могут потребоваться Camera entitlements/подпись.
