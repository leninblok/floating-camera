# Кружок — камера поверх окон для видеообъяснений

Бесплатное приложение для Mac и Windows. Показывает изображение с камеры поверх других приложений, чтобы в записи были видны ты и твоя работа.

Кружок пригодится, когда объясняешь что-то на экране: показываешь коллегам изменения в интерфейсе, разбираешь макет, демонстрируешь код или записываешь урок.

## Как пользоваться

1. Запусти Кружок и разреши доступ к камере. При первом запуске она появится в правом верхнем углу: большой вертикальный прямоугольник 9:16 с тенью и без контура.
2. Перетащи камеру рядом с тем, что показываешь. Правым кликом открой меню: выбери камеру, форму, соотношение сторон, размер и оформление.
3. Начни запись экрана в привычной программе. Кружок запомнит положение камеры и настройки для следующего раза.

Двойной клик по камере включает и выключает фокус: изображение становится крупнее и располагается по центру экрана. Камеру можно перетащить на другой монитор. Тень и прозрачные углы пропускают клики к приложениям под ней.

Чтобы закрыть Кружок, выбери «Закрыть» в меню по правому клику или нажми `⌘Q` на Mac и `Ctrl+Q` на Windows.

## Настройки

- Форма: круг или прямоугольник. Для прямоугольника доступны пропорции 1:1, 4:5 и 9:16.
- Размер: от компактного до большого. Доступные размеры зависят от формы и экрана.
- Оформление: тень и контур можно включать отдельно. Изображение можно отразить по горизонтали.
- Камера: автоматический выбор или конкретное подключённое устройство.

## Установка

Скачай установщик на [странице релизов](https://github.com/leninblok/floating-camera/releases):

- Mac с Apple silicon — файл `Kruzhok-…-mac-arm64.dmg`;
- Mac с Intel — `Kruzhok-…-mac-x64.dmg`;
- Windows x64 — `Kruzhok-…-windows-x64-Setup.exe`.

На Mac открой DMG и перетащи Кружок в «Программы». На Windows запусти EXE. Репозиторий пока закрытый, поэтому скачать установщики могут только люди с доступом к нему.

Сборки пока без цифровой подписи. macOS может остановить первый запуск: после попытки открыть приложение зайди в «Системные настройки» → «Конфиденциальность и безопасность» и нажми «Всё равно открыть» ([инструкция Apple](https://support.apple.com/ru-ru/102445)). Windows тоже может предупредить о неизвестном издателе или заблокировать запуск.

## Запуск из исходников

Понадобится Node.js 22.12 или новее:

```bash
npm ci
npm start
```

При первом запуске macOS попросит доступ к камере.

## Сборка установщиков

```bash
npm run dist:mac:unsigned      # Mac с Apple silicon
npm run dist:mac:unsigned:x64  # Mac с Intel
npm run dist:win               # Windows x64
```

Сборки появятся в `dist/installers`.

Для подписанной и нотариально заверенной сборки Mac нужны данные App Store Connect из `.env.notarize.example` и команда `npm run dist:mac:arm64` или `npm run dist:mac:x64`.

## Проверка изменений

```bash
npm run check
npm test
npm run test:smoke
```

`test:smoke` запускает Electron с синтетическим видео и проверяет появление окна, работу камеры, изменение формы и размера, фокус и перетаскивание. Для диагностики запуска с настоящей камерой используй `KRUZHOK_PROFILE_STARTUP=1 npm start`.
