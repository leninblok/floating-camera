# Floating Camera (Electron)

Простое Electron‑приложение: плавающее круглое видео с фронтальной камеры поверх всех окон.

## Возможности
- Круглое окно 250×250 по умолчанию, прозрачный фон вокруг
- Frameless, всегда поверх всех окон
- Видео с фронтальной камеры (`getUserMedia`)
- Перетаскивание мышью
- Кнопка закрытия (×)
- Горячая клавиша: `S` — временно увеличить до 1000×1000 и центрировать; повторное нажатие возвращает на прежнее место и размер 250×250. В увеличенном состоянии перетаскивание отключено.
- Кроссплатформенно: macOS/Windows/Linux

## Запуск
1. Установите зависимости:
   ```bash
   npm ci
   ```
2. Запустите приложение:
   ```bash
   npm start
   ```

При первом запуске macOS может запросить доступ к камере. Если доступа нет, откройте:
- Системные настройки → Privacy & Security → Camera
- Разрешите доступ для Electron (или Terminal/IDE, если запускаете через них)

## Структура проекта
- `package.json` — скрипты и зависимость Electron
- `main.js` — создание прозрачного всегда‑поверх окна
- `preload.js` — безопасный мост (IPC) для закрытия и изменения размера/позиции
- `index.html` — минимальный UI: круглое видео, крестик
- `renderer.js` — запуск камеры, обработка кнопки и горячей клавиши `S`

## Примечания
- Окно можно растягивать вручную в обычном режиме; в увеличенном режиме (после `S`) растягивание и перетаскивание отключены.
- Если нужна более сильная «поверхность» на macOS (в т.ч. над полноэкранными приложениями), используется уровень `screen-saver`.
- Для продакшн‑сборок на macOS при подписывании приложения могут понадобиться Camera entitlements.
