# Floating Camera

Плавающее окно с изображением с камеры для macOS. Окно остаётся поверх приложений, работает на нескольких мониторах и запоминает положение, размер, выбранную камеру, контур, тень и зеркалирование.

## Что умеет

- Перетаскивание между мониторами; окно не теряется за границами рабочего стола.
- Быстрый выбор камеры, повторное подключение, понятная ошибка и переход в настройки разрешений macOS.
- Двойной клик по видео включает режим фокуса; форма и соотношение сторон сохраняются.
- Круг остаётся чистым: настройки доступны по правому клику или в верхнем меню macOS «Камера».
- В меню можно выбрать источник, форму («Круг» или «Прямоугольник»), соотношение сторон (1:1, 4:5, 9:16), размер, отражение, контур, тень, режим фокуса и закрытие.
- Размеры зависят от формы и доступной области текущего монитора: у круга и квадрата четыре ступени, у 4:5 — три сдержанные, у 9:16 — три высокие. Поэтому один и тот же пункт меню выглядит соразмерно на ноутбуке, внешнем мониторе и при смене разрешения. Выбранный пункт остаётся отмеченным, даже если окно упирается в границы экрана.
- Камера запоминает свой обычный размер и положение. Обычное окно не меняет форму, когда его подносят к краю экрана.
- Единственное сочетание клавиш — `⌘Q`: закрыть камеру и завершить приложение.

## Запуск в разработке

Требуется Node.js 22.12+ (это требование текущей поддерживаемой версии Electron).

```bash
npm ci
npm run check
npm start
```

При таком запуске macOS может попросить доступ к камере для Electron или терминала. В собранном приложении запрос увидит пользователь как `Floating Camera`.

## Обновления

Бесплатная сборка проверяет [GitHub Releases](https://github.com/leninblok/floating-camera/releases) при запуске и через меню «Обновления → Проверить обновления». Если опубликована более новая версия, приложение предлагает открыть страницу релиза. Оно не обновляет unsigned-сборку поверх себя: пользователь скачивает новую DMG/ZIP и устанавливает её обычным способом.

Чтобы уведомление появилось, создайте не draft GitHub Release с тегом формата `v1.2.3` и прикрепите к нему хотя бы один файл `.dmg` или `.zip` для macOS. Версия в `package.json` новой сборки должна совпадать с тегом без `v`.

После перехода на Developer ID Application и notarization можно заменить этот сценарий на полноценное скачивание и установку обновления внутри приложения.

## Подписанная сборка для macOS

Обычная `.app` без подписи и нотарификации не пройдёт Gatekeeper. Для распространения вне Mac App Store Apple требует Developer ID Application certificate, hardened runtime и notarization ticket. Конфигурация этого репозитория делает все три вещи обязательными:

- `mac.forceCodeSigning: true` не даёт случайно выпустить неподписанный артефакт;
- `build/entitlements.mac*.plist` дают Electron только необходимое исключение `allow-jit` для V8;
- `NSCameraUsageDescription` объясняет системный запрос доступа к камере;
- предварительная проверка требует App Store Connect credentials, а `mac.notarize: true` отправляет подписанную сборку в Apple notary service и staples ticket;
- создаются DMG и ZIP для архитектуры текущего Mac.

Перед выпуском нужны:

1. Участие в Apple Developer Program и установленный в активном Keychain сертификат **Developer ID Application**.
2. App Store Connect API key для нотарификации. Скопируйте `.env.notarize.example` за пределы репозитория, заполните переменные окружения из него и не коммитьте их.
3. `notarytool` и `stapler`; они уже входят в установленные на этом Mac Command Line Tools.

Соберите нужную архитектуру:

```bash
npm run dist:mac:arm64 # Apple Silicon
npm run dist:mac:x64   # Intel
```

Проверьте готовый bundle до публикации:

```bash
npm run verify:mac -- "dist/mac-arm64/Floating Camera.app"
```

`codesign`, `spctl` и `stapler` должны завершиться без ошибки. Путь может отличаться в зависимости от версии electron-builder — используйте фактический путь из `dist/`.

Не обходите Gatekeeper снятием quarantine или `xattr`: это не делает выпуск безопасным для других пользователей и не заменяет подпись с нотарификацией.

## Файлы

- `main.js` — безопасный главный процесс, разрешение камеры, окно и несколько мониторов.
- `preload.js` — узкий IPC-мост без Node.js в рендерере.
- `renderer.js`, `index.html` — интерфейс камеры и управление окном.
- `build/entitlements.mac*.plist` — минимальные hardened-runtime entitlements.
- `scripts/verify-macos-release.sh` — проверка подписи, Gatekeeper и stapled ticket.
