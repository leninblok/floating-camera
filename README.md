# Кружок — камера поверх окон для видеообъяснений

Бесплатное приложение для Mac и Windows. Показывает изображение с камеры поверх других приложений, чтобы в записи были видны ты и твоя работа.

Кружок пригодится, когда объясняешь что-то на экране: показываешь коллегам изменения в интерфейсе, разбираешь макет, демонстрируешь код или записываешь урок.

## Как пользоваться

1. Запусти Кружок и разреши доступ к камере. При первом запуске она появится в правом верхнем углу: большой вертикальный прямоугольник 9:16 с тенью и без контура.
2. Перетащи камеру рядом с тем, что показываешь. Правым кликом открой меню: выбери камеру, форму, соотношение сторон, размер и оформление.
3. Начни запись экрана в привычной программе. Кружок запомнит положение камеры и настройки для следующего раза.

Двойной клик по камере включает и выключает фокус: изображение становится крупнее и располагается по центру экрана. Камеру можно перетащить на другой монитор. Тень и прозрачные углы пропускают клики к приложениям под ней.

Чтобы закрыть Кружок, выбери «Закрыть» в меню по правому клику или нажми `⌘Q` на Mac и `Ctrl+Q` на Windows.

## Настройки

- Форма: круг или прямоугольник. Для прямоугольника доступны пропорции 1:1, 4:5 и 9:16.
- Размер: от компактного до большого. Доступные размеры зависят от формы и экрана.
- Оформление: тень и контур можно включать отдельно. Изображение можно отразить по горизонтали.
- Камера: автоматический выбор или конкретное подключённое устройство.

## Установка

Скачай установщик на [странице релизов](https://github.com/leninblok/floating-camera/releases):

- Mac с Apple silicon или Intel — один универсальный файл `Kruzhok-…-mac-universal.dmg`;
- Windows x64 — `Kruzhok-…-windows-x64-Setup.exe`.

На Mac открой DMG и перетащи Кружок в «Программы». На Windows запусти EXE. Репозиторий и релизы публичные; для скачивания вход в GitHub не нужен.

Сборки пока без цифровой подписи. macOS может остановить первый запуск: после попытки открыть приложение зайди в «Системные настройки» → «Конфиденциальность и безопасность» и нажми «Всё равно открыть» ([инструкция Apple](https://support.apple.com/ru-ru/102445)). Windows тоже может предупредить о неизвестном издателе или заблокировать запуск.

## Запуск из исходников

Приложение использует Tauri 2: системный WKWebView на Mac и Microsoft Edge WebView2 на Windows. Chromium и Node.js в установщик не входят.

Понадобятся Node.js 22.12+, стабильный Rust и системные инструменты сборки: Xcode Command Line Tools на Mac; Visual Studio Build Tools с C++ и Windows SDK на Windows. Полный список — в [документации Tauri](https://v2.tauri.app/start/prerequisites/).

```bash
npm ci --ignore-scripts
npm start
```

При первом запуске ОС попросит доступ к камере. Микрофон не используется. Если в Windows нет WebView2, установщик загрузит его из Microsoft; для этого нужен интернет.

## Сборка установщиков

На соответствующей ОС:

```bash
# Mac с Apple silicon и Intel
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm run dist:mac:universal

# Windows x64
npm run dist:win
```

Готовые файлы находятся в `src-tauri/target/<target>/release/bundle/`. Универсальная сборка Mac содержит обе архитектуры в одном приложении. Проверка:

```bash
npm run verify:universal -- "src-tauri/target/universal-apple-darwin/release/bundle/macos/Кружок.app"
```

Локальные сборки Mac по умолчанию получают техническую ad-hoc подпись (`signingIdentity: "-"`); сертификата издателя и нотариального заверения у неё нет. Для подписи и нотариального заверения замените `bundle.macOS.signingIdentity` на свою Developer ID identity (или `null` для выбора через переменные окружения) и используйте стандартные переменные [Tauri для macOS](https://v2.tauri.app/distribute/sign/macos/). `verify:mac` проверяет подпись, Gatekeeper и наличие нотариального штампа у подготовленного приложения.

## Проверка изменений

```bash
npm run check
npm test
npm run prepare:frontend
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm run test:smoke -- /путь/к/собранному/приложению
```

Smoke-проверка запускает настоящее окно Tauri с искусственной камерой, без доступа к физическим устройствам. Она проверяет первый кадр, геометрию всех форм и размеров, фокус, оформление, перемещение, режим поверх окон и сохранение настроек. GitHub Actions выполняет её на Mac и Windows после сборки установщиков.

`src/native-layout.js` и `renderer.js` используются также в демонстрации на сайте. Старый Electron-код сохранён только в `tests/reference/` как эталон для регрессионных тестов; в приложение он не включается. Нативный слой — `src-tauri/src/main.rs`. Настройки из старой версии импортируются при первом запуске.

## Зависимости

Dependabot еженедельно предлагает обновления npm, Cargo и GitHub Actions. Включены GitHub security alerts и security updates. На каждом push/PR и по расписанию выполняются `npm audit` и RustSec `cargo audit` по зафиксированным lock-файлам; PR дополнительно проходит Dependency Review. Обнаруженная уязвимость уровня moderate и выше останавливает npm-проверку, RustSec останавливается на известных уязвимостях для целевых Mac/Windows.

Автоматических слияний обновлений нет: изменения должны пройти проверки. Аудит ищет известные уязвимости и не заменяет проверку кода.

Проект распространяется по [лицензии MIT](LICENSE).

### Известные upstream-предупреждения

На 23 ноября 2026 RustSec сообщает о неподдерживаемых транзитивных `chrono` (RUSTSEC-2026-0543) и `proc-macro-error` (RUSTSEC-2024-0370); исправленной версии в используемой цепочке Tauri пока нет. Они остаются видимыми предупреждениями в CI. Уязвимости и предупреждения `unsound` блокируют проверку.

Исключение RUSTSEC-2024-0429 (`glib 0.18.5`) относится к GTK-ветке Tauri для Linux; в сборках Mac/Windows этот код отсутствует. Зависимость есть в общем Cargo.lock, поэтому GitHub видит её без учёта платформы. Перед добавлением Linux-сборки исключение нужно удалить и обновить GTK/glib-цепочку. Это исключение не отключает остальные проверки.
