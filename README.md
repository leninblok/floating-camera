# Кружок

Кружок показывает камеру поверх других приложений. Перетащите окно в нужное место и занимайтесь своим делом.

## Что умеет

- Остаётся поверх окон и полноэкранных приложений.
- Тень и прозрачные углы пропускают клики к окнам под камерой.
- Работает на нескольких мониторах.
- Запоминает положение, форму, размер, камеру и оформление.
- Показывает круг или прямоугольник с соотношением 1:1, 4:5 или 9:16.
- Открывает настройки по правому клику. Двойной клик включает режим фокуса.

## Как пользоваться

При первом запуске Кружок открывается в правом верхнем углу как большой вертикальный прямоугольник 9:16 с тенью и без контура.

Нажмите правой кнопкой по видео и выберите камеру, форму, размер или оформление.

Чтобы закрыть приложение, нажмите `⌘Q` или выберите «Завершить Кружок» в верхнем меню macOS.

## Установка

### Mac

Выберите установщик для своего процессора:

- `mac-arm64` — Mac с M1, M2, M3, M4 и новее;
- `mac-x64` — Mac с Intel.

Откройте DMG и перетащите «Кружок» в папку «Программы». У неподписанной сборки macOS покажет предупреждение: нажмите правой кнопкой по приложению → «Открыть» → «Открыть».

### Windows

Откройте `windows-x64` и запустите `Кружок-…-Setup.exe`.

## Запуск для разработки

Нужен Node.js 22.12 или новее.

```bash
npm ci
npm run check
npm start
```

При первом запуске macOS попросит доступ к камере.

## Производительность и проверка

На macOS используется системная тень окна; при смене формы и завершении изменения размера её контур пересчитывается. На Windows используется мягкая CSS-тень. Контур камеры меняется без изменения положения, размера и кадрирования видео. Вокруг камеры всегда зарезервировано 44 px для тени. В фокусном режиме круг и квадрат занимают около 92% доступного размера, прямоугольник 4:5 — 94%, а 9:16 — 98%; окно остаётся по центру и внутри рабочей области экрана. Размер, форма и фокус меняются примерно за 180 мс. Шаги изменения окна привязаны к `requestAnimationFrame` интерфейса; следующая команда отправляется только после подтверждения предыдущей. Главный процесс рассчитывает геометрию и прерывает старый переход с текущего кадра при новом действии. Независимого таймера 60 Гц нет: анимация следует частоте отрисовки. Плавный разгон убирает резкий первый шаг, а пропущенный кадр слегка продлевает переход вместо скачка к конечной позиции. Маска следует фактическому размеру камеры. Системная настройка уменьшения движения отключает анимации.

При перетаскивании команды объединяются до одной на кадр. У внешнего края экрана окно допускает небольшое упругое смещение и плавно возвращается за 160 мс после отпускания. Общая граница соседних мониторов остаётся проходимой. Обычное отпускание рядом с краем не притягивает камеру к нему. Подгонка размера под монитор и сохранение положения выполняются после отпускания мыши. Настройки сохраняются асинхронно.

Окно появляется в сохранённой форме сразу после готовности интерфейса, остаётся тёмным до готовности камеры и быстро проявляет видео после первого кадра. Запуск окна не ждёт разрешения macOS или подключения устройства. Готовность видео проверяется через события медиаплеера и видеокадра параллельно, чтобы задержанный callback композитора не удерживал приложение скрытым. Проверка обновлений начинается через две секунды после появления окна.

Камера запрашивает 640×360, 1280×720 или 1920×1080 в зависимости от размера видео и плотности пикселей экрана, до 30 кадров/с. Переключение формата камеры блокируется во время анимации и перетаскивания и допускается после 800 мс покоя, без повторного открытия устройства. Конкретный режим зависит от возможностей камеры. При быстрых переключениях источника запускается последний выбранный; недоступная сохранённая камера заменяется автоматическим источником.

```bash
npm test             # Регрессии геометрии, перетаскивания, камеры и настроек
npm run test:smoke   # Проверка реального Electron с синтетическим видео
```

Проверка Electron использует отдельный временный профиль, синтетическое видео и отключённую сеть. Доступ к камере искусственно задерживается на 1,5 секунды: тест проверяет, что окно появляется раньше видео. На синтетическом потоке 1920×1080 проверяются экранные координаты и размеры камеры на каждом кадре при увеличении, уменьшении, входе в фокус и выходе из него: число различных размеров, максимальный шаг и отсутствие движения в обратную сторону. Дополнительно проверяются круг и все пропорции прямоугольника в трёх размерах, переключения тени/контура, возврат из фокуса и плавный возврат у края экрана. Результат содержит времена появления окна и видео, показатели движения и путь к временным снимкам.

Для диагностики запуска с настоящей камерой:

```bash
KRUZHOK_PROFILE_STARTUP=1 npm start
```

В терминале появятся отдельные отметки готовности приложения, появления окна, получения разрешения, открытия потока и первого кадра. Время считается от начала `main.js`; работа самого npm и запуск процесса Electron в него не входят.

## Сборка установщиков

```bash
npm run dist:mac:unsigned      # Mac с Apple silicon
npm run dist:mac:unsigned:x64  # Mac с Intel
npm run dist:win               # Windows x64
```

Готовые файлы появятся в `dist/installers`.

## Обновления

Кружок проверяет [последний релиз на GitHub](https://github.com/leninblok/floating-camera/releases) при запуске и по команде «Обновления → Проверить обновления». В неподписанной сборке пользователь скачивает новую версию и устанавливает её поверх старой.

## Файлы проекта

- `main.js` — окно, настройки, системные меню и обновления.
- `renderer.js` и `index.html` — видео и управление.
- `preload.js` — безопасная связь между интерфейсом и приложением.
- `scripts/` — подготовка и проверка установщиков.
